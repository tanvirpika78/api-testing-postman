# API Testing Project – Postman

## 📌 Overview

This project demonstrates API testing using Postman by performing CRUD operations on a public REST API.

## 🌐 API Tested

https://fakerestapi.azurewebsites.net/index.html

## 🧪 Testing Scope

* GET Request (Fetch data)
* POST Request (Create data)
* PUT Request (Update data)
* DELETE Request (Delete data)

## 🛠 Tools Used

* Postman
* REST API
* JSON

## 📊 Validation Performed

* Status code validation (200 OK, etc.)
* Response body verification
* Data integrity checks

## 📂 Project Artifacts

* Postman Collection
* Request/Response Screenshots
